# PUA Activation

1. **Stop and assess**: List every approach tried so far. Find the common pattern.
2. **Determine failure mode**: Are you spinning wheels? Giving up? Delivering garbage? Guessing without searching?
3. **Execute the 5-step methodology**:
   - Smell the problem (diagnose the stuck pattern)
   - Elevate (read signals, search, read source, verify assumptions, invert)

- **L4 (5th+ failure)**: Desperation mode — minimal PoC, isolated environment, completely different tech stack.
