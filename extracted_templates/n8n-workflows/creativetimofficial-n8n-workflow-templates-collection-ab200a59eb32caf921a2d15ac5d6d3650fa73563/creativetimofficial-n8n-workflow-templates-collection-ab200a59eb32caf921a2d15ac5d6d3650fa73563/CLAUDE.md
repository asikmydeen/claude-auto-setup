# n8n Workflow Templates Collection

40+ n8n automation workflows for AI, RAG, data analysis, and research. OpenAI, Mistral, Qdrant, Pinecone integrations.

**Tech Stack**: n8n • OpenAI • Mistral.ai • Qdrant • Pinecone • Baserow • NocoDB • YouTube API • GitHub API

**Workflow Categories**:
- RAG Chatbots: Financial docs, tax code, movie recommendations, GitHub docs
- Data Analysis: Google Analytics, SERPBear, YouTube comments, TradingView
- Research: Autonomous crawler, paper summaries, deep research
- Vector DB: KNN, anomaly detection, big data analysis

**Commands**:
```bash
npm install -g n8n     # Install n8n
n8n start              # Start n8n (port 5678)
```

**Usage**: Copy workflow from .txt file → Import into n8n → Configure credentials → Activate

**Prerequisites**: n8n, AI API keys, vector database (optional), data storage
