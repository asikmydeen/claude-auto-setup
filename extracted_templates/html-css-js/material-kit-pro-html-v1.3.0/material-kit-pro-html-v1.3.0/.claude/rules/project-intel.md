## Tech Stack

### CSS Framework
Bootstrap, Material Design

### JavaScript Libraries
- jQuery
- Bootstrap JavaScript components
- Bundled plugins in assets/

## Directory Structure

Key directories:

- **examples/**: Example page implementations
