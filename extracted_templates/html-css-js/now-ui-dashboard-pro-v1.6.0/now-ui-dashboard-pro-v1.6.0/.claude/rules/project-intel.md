# now ui dashuoard pro

## Overview
Premium Admin Dashboard template by Creative Tim

**Type**: Admin Dashboard
**License**: Creative Tim Commercial License

## Tech Stack

### CSS Framework
Bootstrap 4, Now UI

### JavaScript Libraries
- jQuery (for Bootstrap components)
- Chart.js (data visualization)
- FullCalendar (calendar views)
- DataTables (advanced tables)
- Various UI enhancement plugins

### Build Tools
- Gulp (task runner)
- SASS compilation
- Browser-sync for live reload

## Directory Structure

Key directories:
- **assets/**: Static files (CSS, JS, images, fonts)
- **docs/**: Documentation and component reference
- **examples/**: Example page implementations

## Available Pages

Approximately 31 HTML pages including:
- Dashboard home with widgets and charts
- Calendar, data tables, forms
- User management pages
- Settings and profile pages

## Build Commands

- **Install**: `npm install`
- **Development**: `gulp` (watch + browser-sync)
- **Build**: `gulp build`

## Key Features

- Fully responsive design
- Cross-browser compatible


- Data visualization with charts
- Calendar and table integrations
- Pre-built UI components
- Well-documented
