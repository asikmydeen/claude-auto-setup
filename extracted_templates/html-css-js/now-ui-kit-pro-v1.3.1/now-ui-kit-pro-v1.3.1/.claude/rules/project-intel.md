# now ui kit pro

## Overview
Premium UI Kit template by Creative Tim

**Type**: UI Kit
**License**: Creative Tim Commercial License

## Tech Stack

### CSS Framework
Bootstrap 4, Now UI

### JavaScript Libraries
- jQuery (for Bootstrap components)
- Various UI enhancement plugins

### Build Tools
- Gulp (task runner)
- SASS compilation
- Browser-sync for live reload

## Directory Structure

Key directories:
- **assets/**: Static files (CSS, JS, images, fonts)
- **docs/**: Documentation and component reference
- **examples/**: Example page implementations

## Available Pages

Approximately 16 HTML pages including:
- Landing/home page
- About, contact, pricing pages
- Login, signup, profile pages
- Blog and portfolio sections

## Build Commands

- **Install**: `npm install`
- **Development**: `gulp` (watch + browser-sync)
- **Build**: `gulp build`

## Key Features

- Fully responsive design
- Cross-browser compatible



- Pre-built UI components
- Well-documented
