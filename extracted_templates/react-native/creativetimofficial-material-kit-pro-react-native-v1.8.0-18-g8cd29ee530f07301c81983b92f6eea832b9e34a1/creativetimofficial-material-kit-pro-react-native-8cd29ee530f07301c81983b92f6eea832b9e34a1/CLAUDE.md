# Material Kit PRO React Native

Premium React Native mobile template with Material Design, Expo, React Navigation, and Galio UI Framework.

**Tech Stack**: React Native 0.74.5 • Expo 51 • React Navigation 6 • Galio Framework • Material Design • Jest

**Commands**:
- `npm start` - Start Expo dev server
- `npm run android` / `npm run ios` - Run on platform
- `npm test` - Run Jest tests

**Key Directories**:
- `screens/` - Material Design screens
- `components/` - Reusable Material Design components
- `navigation/` - Navigation configuration
- `constants/` - Material theme, colors, assets
