# Soft UI PRO React Native

Premium React Native mobile template with Soft UI Design, TypeScript, Expo 53, chat UI, and calendar support.

**Tech Stack**: React Native 0.79.2 • React 19 • Expo 53 • TypeScript 5.8 • Navigation 7 • Gifted Chat • Calendars • i18n

**Commands**:
- `npm start` - Start Expo dev server
- `npm run android` / `npm run ios` / `npm run web` - Run on platform
- `npm test` / `npm run lint` - Test and lint

**Key Directories**:
- `src/screens/` - Soft UI screens
- `src/components/` - Reusable TypeScript components
- `src/navigation/` - Navigation configuration
- `src/constants/` - Theme, types, config

**Requirements**: Node.js >= 20.0.0
