# Quick Start - Now UI PRO React Native

## Prerequisites
- Node.js >= 14.x
- npm or yarn
- Expo CLI: `npm install -g expo-cli`
- Expo Go app on your mobile device (iOS/Android)

## Setup
```bash
npm install
npm start
```

## First Run
1. Install dependencies
2. Start dev server with `npm start`
3. Scan QR code with Expo Go app
4. Or press 'a' for Android emulator / 'i' for iOS simulator

## Linting
```bash
npm run lint    # Check code style (Airbnb)
```

## Important
- Requires Expo SDK ~51.0
- Uses React Native 0.74.5 with Now UI Design
- Navigation pre-configured with React Navigation 6.x
- ESLint configured with Airbnb style guide
