# Now UI PRO React Native

Premium React Native mobile template with Now UI Design System, Expo, React Navigation, and Galio UI Framework.

**Tech Stack**: React Native 0.74.5 • Expo 51 • React Navigation 6 • Galio Framework • SVG Support • ESLint

**Commands**:
- `npm start` - Start Expo dev server
- `npm run android` / `npm run ios` - Run on platform
- `npm run lint` - Run ESLint (Airbnb config)

**Key Directories**:
- `screens/` - Now UI Design screens
- `components/` - Reusable Now UI components
- `navigation/` - Navigation configuration
- `constants/` - Theme, colors, assets
