# Argon PRO React Native

Premium React Native mobile template with Expo, React Navigation, and Galio UI Framework.

**Tech Stack**: React Native 0.74.5 • Expo 51 • React Navigation 6 • Galio Framework • JavaScript

**Commands**:
- `npm start` - Start Expo dev server
- `npm run android` / `npm run ios` - Run on platform

**Key Directories**:
- `screens/` - 24 pre-built screens
- `components/` - Reusable UI components
- `navigation/` - Navigation configuration
- `constants/` - Theme, colors, assets
