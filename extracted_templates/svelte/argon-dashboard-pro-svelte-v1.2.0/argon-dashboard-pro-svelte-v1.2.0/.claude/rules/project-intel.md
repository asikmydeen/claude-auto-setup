# Project Intelligence: Argon Dashboard Pro Svelte

## Overview
- **Name**: Argon Dashboard Pro Svelte
- **Type**: Svelte Template
- **Description**: Premium Svelte dashboard with Argon design system and Bootstrap 4

## Tech Stack
- Svelte 3.38.3
- TypeScript
- Rollup bundler
- Bootstrap 4.3.1
- FullCalendar, DataTables, FusionCharts
- Google Maps integration

## Directory Structure
```
src/           - Source code (components, pages, services)
public/        - Static assets
documentation/ - Project documentation
```

## Key Commands
- **Development**: `rollup -c -w`
- **Build**: `rollup -c`
- **Test**: `npm test`
- **Clean Install**: `rm -rf node_modules package-lock.json && npm install`

## Patterns & Conventions
- Uses TypeScript for type safety
- Component-based architecture
- Material/Bootstrap design system integration
- Modular routing structure

## Known Gotchas
- Run `npm install` before first use
- Node.js 14+ required
- Some templates require specific Angular/React/Vue/Svelte CLI versions
