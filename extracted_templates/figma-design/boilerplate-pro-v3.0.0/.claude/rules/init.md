# Quick Start - Horizon UI Boilerplate PRO

## Prerequisites
- Figma desktop app or web
- Node.js and npm

## Setup
```bash
# Open Figma file
# File → Open → "Horizon UI Boilerplate - Figma Version.fig"

# Extract and run code
unzip boilerplate-pro-main.zip
cd boilerplate-pro-main
npm install
npm run dev
```

## Important
- Figma file contains full design system
- Code boilerplate in zip file
- Design tokens match between Figma and code
