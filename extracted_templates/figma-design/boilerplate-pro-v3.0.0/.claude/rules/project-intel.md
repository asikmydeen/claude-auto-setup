# Horizon UI Boilerplate PRO

## Overview
Premium Figma design file + React/Next.js boilerplate. Complete design system and developer handoff package.

## Package Contents
- **Figma File**: `Horizon UI Boilerplate - Figma Version.fig` (design system)
- **Code Boilerplate**: `boilerplate-pro-main.zip` (React/Next.js code)

## Design System (Figma)
- Component library with design tokens
- Dashboard pages and UI patterns
- Responsive layouts
- Color system, typography, spacing
- Icon library
- Dev handoff specifications

## Code Boilerplate (Expected in zip)
- Next.js/React framework
- Pre-built dashboard components
- Responsive layouts matching Figma
- Component library
- Theme system

## Usage Workflow
1. Open `.fig` file in Figma for design
2. Extract `boilerplate-pro-main.zip` for code
3. Install: `npm install`
4. Develop: `npm run dev`
5. Build components matching Figma designs
