# Horizon UI Boilerplate PRO

Figma design system + React/Next.js boilerplate. Complete design-to-code package.

**Package**: Figma Design File (.fig) + Code Boilerplate (.zip with Next.js/React)

**Features**: Component library, design tokens, responsive layouts, dashboard UI

**Usage**: Design in Figma → Extract zip → `npm install && npm run dev`

**Prerequisites**: Figma, Node.js/npm
