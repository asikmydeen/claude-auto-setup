# Horizon AI Boilerplate - shadcn/ui PRO (Design Only)

## Overview
Premium Figma design file for AI dashboards using shadcn/ui design system.

## Package Contents
- **Figma File**: `canvas.fig` (complete AI dashboard design system)

## Design System Features
- AI-focused UI components
- shadcn/ui design patterns
- Component library
- Responsive layouts
- Tailwind CSS design tokens
- Color system (dark/light mode)
- Typography system
- Spacing and sizing
- AI interface patterns (chat, analytics, etc.)

## Design Tokens
- Colors: Primary, secondary, accent, neutrals
- Typography: Font families, sizes, weights
- Spacing: Consistent spacing scale

- Shadows: Elevation system

## Usage
1. Open `canvas.fig` in Figma desktop or web
2. Duplicate components to your project
3. Customize colors and typography
4. Export assets as needed
5. Use design tokens in your code
6. Reference component specs for development

## Developer Handoff
- Use Figma Inspect for measurements
- Export CSS/Tailwind classes
- Copy design tokens
- Export icons and images
- Reference component states
- Note responsive breakpoints

- React with Radix UI + Tailwind
