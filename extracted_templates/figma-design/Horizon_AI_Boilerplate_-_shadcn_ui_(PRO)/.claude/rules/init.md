# Quick Start - Horizon AI Boilerplate shadcn/ui PRO

## Prerequisites
- Figma desktop app or Figma web access

## Setup
```bash
# Open in Figma
# File → Open → Select canvas.fig
```

## First Steps
1. Open Figma file
2. Explore component library
3. Review design tokens (colors, typography, spacing)
4. Duplicate components to your project
5. Customize for your needs
6. Export assets if needed

## Developer Handoff
- Use Figma Inspect mode
- Export design tokens to Tailwind config
- Reference component specifications
- Export icons and images

## Important
- Design-only package (no code included)
- Compatible with shadcn/ui and Tailwind CSS
- Full AI dashboard design system
- Responsive design included
