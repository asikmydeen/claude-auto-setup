# Horizon AI Boilerplate - shadcn/ui PRO (Full Pack)

Figma + Next.js/shadcn/ui boilerplate for AI dashboards. Complete design-to-code package.

**Package**: Figma Design (.fig) + Code (.zip with Next.js 14+/TypeScript/shadcn/ui/Tailwind)

**Features**: AI dashboard components, shadcn/ui library, Radix UI, Tailwind CSS, dark mode

**Usage**: Design in Figma → Extract zip → `npm install && npm run dev`

**Tech**: Next.js 14+ • shadcn/ui • Radix UI • Tailwind CSS • TypeScript
