# Quick Start - Horizon AI Boilerplate shadcn/ui PRO

## Prerequisites
- Figma app
- Node.js 18+ and npm
- Code editor

## Setup
```bash
# Extract code boilerplate
unzip horizon-ui-boilerplate-shadcn-pro-3.0.2.zip
cd horizon-ui-boilerplate-shadcn-pro-3.0.2

# Install dependencies
npm install

# Start development
npm run dev
```

## Figma
Open `Horizon AI Boilerplate - shadcn:ui (PRO).fig` in Figma

## Important
- Uses Next.js 14+ with App Router
- shadcn/ui components (Radix + Tailwind)
- TypeScript required
- AI-focused interface components
