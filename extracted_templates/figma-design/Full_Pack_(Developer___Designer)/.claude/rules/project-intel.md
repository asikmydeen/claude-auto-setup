# Horizon AI Boilerplate - shadcn/ui PRO (Full Pack)

## Overview
Premium full pack with Figma design file + Next.js/shadcn/ui boilerplate. Developer and designer bundle.

## Package Contents
- **Figma File**: `Horizon AI Boilerplate - shadcn:ui (PRO).fig`
- **Code Boilerplate**: `horizon-ui-boilerplate-shadcn-pro-3.0.2.zip`

## Design System (Figma)
- AI-focused design components
- shadcn/ui design tokens
- Component library
- Responsive layouts
- Color system, typography
- AI interface patterns

## Code Boilerplate (Expected)
### Tech Stack
- **Framework**: Next.js 14+
- **UI Library**: shadcn/ui (Radix UI + Tailwind)
- **Styling**: Tailwind CSS
- **Language**: TypeScript

### Key Features
- AI dashboard components
- shadcn/ui component library
- Tailwind CSS styling
- TypeScript type safety
- Dark/light mode
- Responsive design

## Usage Workflow
1. Design in Figma with AI components
2. Extract code boilerplate from zip
3. Install dependencies: `npm install`
4. Start dev: `npm run dev`
5. Build AI interfaces matching Figma
