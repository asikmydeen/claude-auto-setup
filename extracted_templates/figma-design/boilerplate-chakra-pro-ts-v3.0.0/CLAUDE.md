# Horizon UI Boilerplate - Chakra UI Pro (TypeScript)

Figma design system + React/Next.js boilerplate with Chakra UI and TypeScript. Complete design-to-code package.

**Package**: Figma Design File (.fig) + Code Boilerplate (.zip with Next.js/TypeScript/Chakra UI)

**Design Features**: Component library, design tokens, responsive layouts, dark/light mode, icon library

**Code Stack**: Next.js • TypeScript • Chakra UI • React

**Usage**:
1. Design in Figma with component library
2. Extract code boilerplate from zip
3. `npm install && npm run dev`
4. Build components matching Figma designs

**Prerequisites**: Figma app, Node.js/npm
