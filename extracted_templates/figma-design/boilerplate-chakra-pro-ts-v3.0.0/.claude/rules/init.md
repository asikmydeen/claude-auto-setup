# Quick Start - Horizon UI Boilerplate Chakra Pro

## Prerequisites
- Figma desktop app or Figma web
- Node.js and npm (for code boilerplate)
- Code editor (VS Code recommended)

## Figma Setup
```bash
# Open the .fig file in Figma
# File → Open → Select "Horizon UI Boilerplate - Figma Version.fig"
```

## Code Setup
```bash
# Extract the zip file
unzip boilerplate-chakra-pro-main.zip
cd boilerplate-chakra-pro-main

# Install dependencies
npm install

# Start development server
npm run dev
```

## First Steps
1. Open Figma file to explore design system
2. Extract code boilerplate
3. Install dependencies
4. Start dev server
5. Build components matching Figma designs

## Important
- Figma file contains full design system
- Code uses Chakra UI + TypeScript
- Design tokens should match between Figma and code
- Responsive breakpoints defined in both
