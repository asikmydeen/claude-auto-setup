# material-dashboard-3-pro-react

React version of Material Dashboard 3 PRO by Creative Tim

**Framework:** React 18.3.1 + Material UI

## Quick Commands

```bash
npm install          # Install dependencies
DISABLE_ESLINT_PLUGIN=true GENERATE_SOURCEMAP=false react-scripts start  # Start dev server
GENERATE_SOURCEMAP=false react-scripts build   # Build for production
react-scripts test       # Run tests
```

## Key Directories

- `src/components/` - Reusable UI components
- `src/views/` or `src/pages/` - Page-level components
- `src/assets/` - Static assets (images, styles)
- `src/layouts/` - Layout wrapper components

## Tech Stack

- **UI Library:** Material UI
- **Styling:** Emotion
- **State:** React Hooks
- **Routing:** React Router
- **Build:** Create React App

## Code Conventions

- Functional components with hooks
- Material UI components for UI
- Consistent import ordering (React, libraries, local)
