# vision-dashboard-react-pro

Chakra UI Create React App Template

**Framework:** React ^17.0.2 + Chakra UI

## Quick Commands

```bash
npm install          # Install dependencies
react-scripts start  # Start dev server
react-scripts build && gulp licenses   # Build for production
react-scripts test --env=jsdom       # Run tests
```

## Key Directories

- `src/components/` - Reusable UI components
- `src/views/` or `src/pages/` - Page-level components
- `src/assets/` - Static assets (images, styles)
- `src/layouts/` - Layout wrapper components

## Tech Stack

- **UI Library:** Chakra UI
- **Styling:** Emotion
- **State:** React Hooks
- **Routing:** React Router
- **Build:** Create React App

## Code Conventions

- Functional components with hooks
- Chakra UI components for UI
- Consistent import ordering (React, libraries, local)
