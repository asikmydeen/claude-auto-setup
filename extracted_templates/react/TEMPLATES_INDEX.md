## Quick Start (Any Template)

```bash
cd <template-directory>
npm install
npm start
```

## Common Commands

All templates use similar commands:
- `npm start` or `react-scripts start` - Development server
- `npm run build` or `react-scripts build` - Production build
- `npm test` - Run tests (if configured)

## Template Categories

**Dashboards**: Most templates are dashboard/admin templates with:
- Multiple page layouts
- Data visualization (charts, tables)
- Form components
- Authentication examples
- Responsive design

**Design Systems**: A few templates are marketing/presentation focused:
- Landing pages
- Component showcases
- Marketing sections

## Notes

- All templates use Create React App (no Vite templates)
- Most templates are React 16-18
- All include React Router for navigation
- Material UI is the most common UI library (9 templates)
- Bootstrap/Reactstrap variants available (9 templates)
- Chakra UI modern approach (3 templates)
- Ant Design for enterprise UIs (1 template)
