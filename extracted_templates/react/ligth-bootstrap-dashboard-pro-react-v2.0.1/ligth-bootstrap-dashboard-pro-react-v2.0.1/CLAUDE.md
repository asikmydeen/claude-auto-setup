# light-bootstrap-dashboard-pro-react

Bootstrap/Reactstrap Create React App Template

**Framework:** React 18.2.0 + Bootstrap/Reactstrap

## Quick Commands

```bash
npm install          # Install dependencies
react-scripts start  # Start dev server
react-scripts build   # Build for production
react-scripts test       # Run tests
```

## Key Directories

- `src/components/` - Reusable UI components
- `src/views/` or `src/pages/` - Page-level components
- `src/assets/` - Static assets (images, styles)
- `src/layouts/` - Layout wrapper components

## Tech Stack

- **UI Library:** Bootstrap/Reactstrap
- **Styling:** CSS/SCSS
- **State:** React Hooks
- **Routing:** React Router
- **Build:** Create React App

## Code Conventions

- Functional components with hooks
- Bootstrap/Reactstrap components for UI
- Consistent import ordering (React, libraries, local)
