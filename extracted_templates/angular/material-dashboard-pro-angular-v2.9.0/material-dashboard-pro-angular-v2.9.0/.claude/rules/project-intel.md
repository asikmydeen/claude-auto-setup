# Project Intelligence: Material Dashboard Pro Angular

## Overview
- **Name**: Material Dashboard Pro Angular
- **Type**: Angular Template
- **Description**: Premium Angular dashboard with Material Design 2 components and Bootstrap

## Tech Stack
- Angular 15.2.0
- Angular Material 15.2.0
- TypeScript 4.9.4
- Bootstrap 4 with Material Design
- Charts (Chartist), FullCalendar, DataTables

## Directory Structure
```
src/           - Source code (components, pages, services)
public/        - Static assets
documentation/ - Project documentation
```

## Key Commands
- **Development**: `ng serve`
- **Build**: `ng build`
- **Test**: `ng test`
- **Clean Install**: `rm -rf node_modules package-lock.json && npm install`

## Patterns & Conventions
- Uses TypeScript for type safety
- Component-based architecture
- Material/Bootstrap design system integration
- Modular routing structure

## Known Gotchas
- Run `npm install` before first use
- Node.js 14+ required
- Some templates require specific Angular/React/Vue/Svelte CLI versions
