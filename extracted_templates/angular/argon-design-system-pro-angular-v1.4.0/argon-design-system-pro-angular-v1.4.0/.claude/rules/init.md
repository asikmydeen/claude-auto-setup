# Quick Start

## Prerequisites
- Node.js 14+ and npm
- Angular CLI (if required)

## Setup
1. Install dependencies: `npm install`
2. Start dev server: `ng serve`
3. Open browser to http://localhost:4200 (Angular) or http://localhost:3000 (Next/Nuxt)

## Environment
- No .env required for basic setup
- Check documentation/ folder for advanced configuration
