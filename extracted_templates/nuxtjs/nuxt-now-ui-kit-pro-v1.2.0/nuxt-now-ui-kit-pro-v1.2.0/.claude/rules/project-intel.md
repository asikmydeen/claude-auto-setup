# Project Intelligence: Nuxt Now UI Kit Pro

## Overview
- **Name**: Nuxt Now UI Kit Pro
- **Type**: Nuxt.js Template
- **Description**: Premium Nuxt.js UI kit with Now UI design components

## Tech Stack
- Nuxt (latest)
- Vue 3
- TypeScript
- Bootstrap
- Now UI Design

## Directory Structure
```
src/           - Source code (components, pages, services)
public/        - Static assets
documentation/ - Project documentation
```

## Key Commands
- **Development**: `nuxt dev`
- **Build**: `nuxt build`
- **Test**: `npm test`
- **Clean Install**: `rm -rf node_modules package-lock.json && npm install`

## Patterns & Conventions
- Uses TypeScript for type safety
- Component-based architecture
- Material/Bootstrap design system integration
- Modular routing structure

## Known Gotchas
- Run `npm install` before first use
- Node.js 14+ required
- Some templates require specific Angular/React/Vue/Svelte CLI versions
