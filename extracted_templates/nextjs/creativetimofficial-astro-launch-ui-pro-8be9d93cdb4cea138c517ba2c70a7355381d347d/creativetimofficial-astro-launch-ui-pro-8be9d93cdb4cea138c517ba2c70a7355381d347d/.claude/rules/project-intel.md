# Project Intelligence: Astro Launch UI Pro

## Overview
- **Name**: Astro Launch UI Pro
- **Type**: Next.js/Astro Template
- **Description**: Premium landing page template with modern UI components

## Tech Stack
- Next.js/Astro
- React
- TypeScript
- Modern UI components

## Directory Structure
```
src/           - Source code (components, pages, services)
public/        - Static assets
documentation/ - Project documentation
```

## Key Commands
- **Development**: `npm run dev`
- **Build**: `npm run build`
- **Test**: `npm test`
- **Clean Install**: `rm -rf node_modules package-lock.json && npm install`

## Patterns & Conventions
- Uses TypeScript for type safety
- Component-based architecture
- Material/Bootstrap design system integration
- Modular routing structure

## Known Gotchas
- Run `npm install` before first use
- Node.js 14+ required
- Some templates require specific Angular/React/Vue/Svelte CLI versions
