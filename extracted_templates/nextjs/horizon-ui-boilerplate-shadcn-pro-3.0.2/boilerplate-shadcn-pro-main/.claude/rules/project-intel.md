# Project Intelligence: Horizon AI Boilerplate Shadcn Pro

## Overview
- **Name**: Horizon AI Boilerplate Shadcn Pro
- **Type**: Next.js Template
- **Description**: Premium Next.js AI boilerplate with Shadcn UI, Supabase, and Stripe integration

## Tech Stack
- Next.js 15.1.6
- React 19.0.0
- TypeScript 5.4.5
- Tailwind CSS 3.4.3
- Shadcn UI components
- Supabase auth & database
- Stripe payments
- OpenAI integration

## Directory Structure
```
src/           - Source code (components, pages, services)
public/        - Static assets
documentation/ - Project documentation
```

## Key Commands
- **Development**: `next dev`
- **Build**: `next build`
- **Test**: `npm test`
- **Clean Install**: `rm -rf node_modules package-lock.json && npm install`

## Patterns & Conventions
- Uses TypeScript for type safety
- Component-based architecture
- Material/Bootstrap design system integration
- Modular routing structure

## Known Gotchas
- Run `npm install` before first use
- Node.js 14+ required
- Some templates require specific Angular/React/Vue/Svelte CLI versions
