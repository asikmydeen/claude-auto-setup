# Argon PRO Flutter

Premium Flutter mobile app template with Argon Design System. Cross-platform for iOS and Android.

**Tech Stack**: Flutter • Dart 2.7-3.0 • Material Design • Font Awesome • OpenSans Font

**Commands**:
- `flutter pub get` - Install dependencies
- `flutter run` - Run app (hot reload enabled)
- `flutter build apk/ios` - Build for production

**Key Directories**:
- `lib/` - Dart source code
- `assets/img/` - Images and backgrounds
- `assets/fonts/` - OpenSans font family

**Features**: Carousels, URL launcher, custom fonts, Argon Design components
