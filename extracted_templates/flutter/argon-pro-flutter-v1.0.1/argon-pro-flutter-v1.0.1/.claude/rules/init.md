# Quick Start - Argon PRO Flutter

## Prerequisites
- Flutter SDK (Dart 2.7 - 3.0)
- Android Studio / Xcode (for emulators)
- VS Code or Android Studio with Flutter plugin

## Setup
```bash
flutter doctor          # Verify Flutter installation
flutter pub get         # Install dependencies
flutter run             # Run on connected device/emulator
```

## First Run
1. Install Flutter SDK: https://flutter.dev/docs/get-started/install
2. Run `flutter doctor` to check for issues
3. Open project in IDE
4. Get dependencies: `flutter pub get`
5. Connect device or start emulator
6. Run: `flutter run`

## Important
- Dart SDK 2.7.0 - 3.0.0 required
- Android/iOS emulator or physical device needed
- Hot reload available during development (press 'r')
