# Now UI PRO Flutter

Premium Flutter mobile app template with Now UI Design System. Modern cross-platform for iOS and Android with Flutter 3.22+.

**Tech Stack**: Flutter 3.22+ • Dart 3.0+ • Material Design • Font Awesome 10 • Montserrat Font • flutter_lints

**Commands**:
- `flutter pub get` - Install dependencies
- `flutter run` - Run app (hot reload enabled)
- `flutter analyze` - Check code quality
- `flutter build apk/ios` - Build for production

**Key Directories**:
- `lib/` - Dart source code
- `assets/imgs/` - Now UI images and backgrounds
- `assets/fonts/` - Montserrat font family

**Features**: Carousels, URL launcher, custom fonts, Now UI Design components, modern Flutter 3.22+ support

**Requirements**: Flutter >= 3.22.0, Dart >= 3.0.0
