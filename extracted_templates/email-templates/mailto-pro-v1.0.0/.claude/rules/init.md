# Quick Start - Mailto PRO Email Templates

## Prerequisites
- HTML editor or text editor
- Email service provider account (Mailchimp, SendGrid, etc.)
- Image hosting (CDN or web server)

## Usage
```bash
# 1. Choose template
cd "Templates/[Template Name]/Code"

# 2. Open index.html in editor
# 3. Customize content, links, images
# 4. Copy HTML to your email platform
```

## First Run
1. Browse preview images in each template's `Preview/` folder
2. Select template for your use case
3. Open `Code/index.html` in HTML editor
4. Replace placeholder text and images
5. Host images on CDN (use absolute URLs)
6. Copy final HTML to your email service
7. Test send before campaign

## Important
- Use absolute URLs for all images
- Inline CSS is already applied
- Test in multiple email clients
- Include unsubscribe link for marketing emails
- Keep total size under 100KB
- Provide plain text alternative
