## Usage Workflow
1. Choose template for your use case
2. Copy HTML from `Templates/[Name]/Code/index.html`
3. Customize text, links, images
4. Replace placeholder images with your hosted images
5. Test in email client preview tools
6. Send via your email service provider (Mailchimp, SendGrid, etc.)

## Customization
- Replace text content
- Update links and CTAs
- Swap images (use CDN URLs)
- Adjust colors (inline styles)
- Add tracking pixels
- Modify layout as needed

## Best Practices
- Always use absolute URLs for images
- Host images on CDN or reliable server
- Keep file size under 100KB
- Test across multiple email clients
- Use alt text for all images
- Include plain text version
- Add unsubscribe link for marketing emails
