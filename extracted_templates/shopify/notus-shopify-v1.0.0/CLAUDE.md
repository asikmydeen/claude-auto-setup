# Notus Shopify Theme

Premium Shopify e-commerce theme with Notus Design System, Tailwind CSS, and Liquid templating. 34 languages supported.

**Tech Stack**: Shopify Liquid • Tailwind CSS • Vanilla JS • Notus Design System

**Commands**:
- `shopify theme dev` - Local development server
- `shopify theme push` - Deploy to Shopify
- `shopify theme check` - Validate theme

**Key Directories**:
- `sections/` - 25+ reusable sections
- `snippets/` - 28 reusable components
- `templates/` - 18 page templates
- `assets/` - CSS, JS, images
- `locales/` - 34 language files

**Prerequisites**: Shopify store, Shopify CLI
