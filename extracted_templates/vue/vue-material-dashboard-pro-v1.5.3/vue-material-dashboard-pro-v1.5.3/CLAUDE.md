# Vue Material Dashboard PRO

Vue 2 dashboard with Vue Material component library.

**Framework**: Vue 2.7.14 + Vue Material 1.0.0-beta-15

**Commands**:
- `npm run serve` - Dev server
- `npm run build` - Build
- `npm run lint` - Lint

**Key Directories**:
- `src/components/` - Components
- `src/pages/` - Pages

**Conventions**:
- Vue Material (md-* prefix)
- Material Design
- Chartist charts
