# Vue Material Dashboard PRO

## Project Overview
Premium Vue 2 admin dashboard with Vue Material component library and Material Design.

## Tech Stack
- **Framework**: Vue 2.7.14
- **UI Library**: Vue Material 1.0.0-beta-15
- **Build Tool**: Vue CLI 5.0.8
- **Router**: Vue Router 3.6.5
- **Validation**: vee-validate 3.4.15
- **CSS**: SASS 1.71.1

## Key Dependencies
- Vue Material 1.0.0-beta-15 (Material Design components)
- FullCalendar 6.1.11
- Chartist 0.11.4
- nouislider 15.7.1
- SweetAlert2 11.10.5
- Perfect Scrollbar 1.5.5
- jvectormap-next 3.1.1 (vector maps)
- @tweenjs/tween.js 20.0.3
- vue-clickaway 2.2.2

## Scripts
- `npm run serve` / `npm run dev` - Dev server with auto-open
- `npm run build` - Production build
- `npm run lint` - Lint code
- `npm run deploy` - Deploy to gh-pages
- `npm run install:clean` - Clean reinstall

## Key Patterns
- Vue Material component library (md-* prefix)
- Material Design principles
- Chartist for responsive charts
- jVectorMap for map visualizations
- Perfect Scrollbar for custom scrollbars
- Tween.js for animations

## Known Gotchas
- Vue Material beta version (API may change)
- Vue 2.7 with CLI 5.0.8 (modern tooling)
- Chartist (not Chart.js)
