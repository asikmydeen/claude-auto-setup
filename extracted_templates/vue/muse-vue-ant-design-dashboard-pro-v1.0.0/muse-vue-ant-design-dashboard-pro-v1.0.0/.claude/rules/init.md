# Muse Vue Ant Design Dashboard PRO - Quick Start

## Prerequisites
- Node.js 12+ and npm 5+
- Python 2.7 (for node-sass compilation)

## Setup Steps
1. Install dependencies: `npm install`
2. Start dev server: `npm run serve`
3. Build for production: `npm run build`

## Environment
No environment configuration required for basic usage.

## First Run
- Dev server: `http://localhost:8080`
- Hot reload enabled
