# Muse Vue Ant Design Dashboard PRO

Premium Vue 2 dashboard with Ant Design Vue component library.

**Framework**: Vue 2.6.14 + Ant Design Vue 1.7.7

**Commands**:
- `npm run serve` - Dev server
- `npm run build` - Production build

**Key Directories**:
- `src/components/` - UI components
- `src/views/` - Pages
- `src/assets/` - Static files

**Conventions**:
- Ant Design components (a-* prefix)
- SCSS for styling
