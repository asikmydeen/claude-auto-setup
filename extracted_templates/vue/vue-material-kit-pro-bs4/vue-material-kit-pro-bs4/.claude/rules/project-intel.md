# Vue Material Kit PRO (Bootstrap 4)

## Project Overview
Premium Vue 2 UI kit with Vue Material and Material Design for marketing and landing pages.

## Tech Stack
- **Framework**: Vue 2.7.14
- **UI Library**: Vue Material 1.0.0-beta-15
- **Build Tool**: Vue CLI 4.5.19
- **Router**: Vue Router 3.5.1
- **CSS**: SASS 1.56.1

## Key Dependencies
- Vue Material 1.0.0-beta-15
- Element UI 2.15.12 (additional components)
- vue-lazyload 1.3.4 (image lazy loading)
- vue-product-zoomer 3.0.1 (product image zoom)
- vue2-transitions 0.3.0 (animations)
- AOS 3.0.0-beta.6 (scroll animations)
- nouislider 15.6.1
- v-tooltip 2.1.3
- vue-clickaway 2.2.2

## Scripts
- `npm run serve` / `npm run dev` - Dev server with auto-open
- `npm run build` - Production build
- `npm run lint` - Lint code
- `npm run install:clean` - Clean reinstall
