# Vue Material Kit PRO (Bootstrap 4)

Vue 2 UI kit with Vue Material. E-commerce and marketing focused.

**Framework**: Vue 2.7.14 + Vue Material 1.0.0-beta-15

**Commands**:
- `npm run serve` - Dev server
- `npm run build` - Build
- `npm run lint` - Lint

**Key Directories**:
- `src/components/` - Components
- `src/views/` - Pages

**Conventions**:
- Vue Material (md-*)
- Product zoom
- Lazy loading
