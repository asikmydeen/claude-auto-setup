# Vue Argon Dashboard PRO (Bootstrap 4)

Vue 3 dashboard with Bootstrap 4 and Argon design.

**Framework**: Vue 3.0.11 + Vue CLI 4.5.19 + Bootstrap 4.6.0

**Commands**:
- `npm run serve` - Dev
- `npm run build` - Build
- `npm run lint` - Lint

**Key Directories**:
- `src/components/` - Components
- `src/views/` - Pages

**Conventions**:
- Bootstrap 4 classes
- vee-validate for forms
- Element Plus components
