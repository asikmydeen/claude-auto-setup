# Vuetify Soft UI Dashboard PRO - Quick Start

## Prerequisites
- Node.js 12+
- npm 5+

## Setup Steps
1. `npm install`
2. `npm run serve`
3. `npm run build` for production

## Environment
Vuetify configured with Soft UI theme in `src/plugins/vuetify.js`.

## First Run
- Vuetify + Soft UI hybrid
- 3D graphics support
