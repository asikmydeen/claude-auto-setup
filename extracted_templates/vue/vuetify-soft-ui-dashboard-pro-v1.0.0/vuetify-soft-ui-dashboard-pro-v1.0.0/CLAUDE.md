# Vuetify Soft UI Dashboard PRO

Vue 2 dashboard with Vuetify components and Soft UI design.

**Framework**: Vue 2.6.14 + Vuetify 2.5.10

**Commands**:
- `npm run serve` - Dev server
- `npm run build` - Build
- `npm run lint` - Lint

**Key Directories**:
- `src/components/` - Components
- `src/views/` - Pages
- `src/plugins/` - Vuetify + Soft UI config

**Conventions**:
- Vuetify (v-* prefix)
- Soft UI theming
- Three.js for 3D
