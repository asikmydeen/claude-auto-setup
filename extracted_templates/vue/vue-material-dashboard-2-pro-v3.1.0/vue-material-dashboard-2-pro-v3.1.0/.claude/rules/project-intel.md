# Vue Material Dashboard 2 PRO

## Project Overview
Premium Vue 3 admin dashboard with Material Design, Bootstrap 5, and FontAwesome icons.

## Tech Stack
- **Framework**: Vue 3.4.19
- **Build Tool**: Vue CLI 5.0.8
- **UI Framework**: Bootstrap 5.3.3 (Material Design theme)
- **State Management**: Vuex 4.1.0
- **Router**: Vue Router 4.3.0
- **Icons**: FontAwesome 6.5.1 (full suite)
- **CSS**: SASS 1.71.1

## Key Dependencies
- FontAwesome (core, solid, regular, brands, vue-fontawesome)
- FullCalendar 6.1.11
- Chart.js 4.4.1
- Choices.js 10.2.0
- Dragula 3.7.3
- Dropzone 6.0.0-beta.2
- jKanban 1.3.1
- jsvectormap 1.5.3 (vector maps)
- PhotoSwipe 5.4.3
- Quill 1.3.7
- vue-sweetalert2 5.0.5

## Scripts
- `npm run serve` - Dev server
- `npm run build` - Production build
- `npm run lint` - Lint code

## Key Patterns
- Material Design with Bootstrap 5
- Vue 3 Composition API
- FontAwesome icon components
- Vuex for state management
- Vector maps via jsvectormap
- Material elevation and shadows
- Custom Material color palette

## Known Gotchas
- Uses consolidate 1.0.1 override
- Full FontAwesome suite (large bundle)
- Material Design on Bootstrap 5
