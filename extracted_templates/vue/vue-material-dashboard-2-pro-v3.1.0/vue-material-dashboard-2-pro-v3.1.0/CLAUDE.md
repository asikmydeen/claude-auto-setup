# Vue Material Dashboard 2 PRO

Vue 3 dashboard with Material Design and Bootstrap 5.

**Framework**: Vue 3.4.19 + Vue CLI 5.0.8 + Bootstrap 5.3.3

**Commands**:
- `npm run serve` - Dev server
- `npm run build` - Build
- `npm run lint` - Lint

**Key Directories**:
- `src/components/` - Components
- `src/views/` - Pages
- `src/store/` - Vuex

**Conventions**:
- Material Design
- FontAwesome icons
- Vue 3 Composition API
