# Vue Light Bootstrap Dashboard PRO

Lightweight Vue 2 dashboard with Bootstrap 4 and Chartist.

**Framework**: Vue 2.7.14 + Element UI + Bootstrap 4.6.0

**Commands**:
- `npm run dev` - Dev server
- `npm run build` - Build
- `npm run lint` - Lint

**Key Directories**:
- `src/components/` - Components
- `src/views/` - Pages

**Conventions**:
- Chartist for charts
- Element UI components
- Form wizard support
