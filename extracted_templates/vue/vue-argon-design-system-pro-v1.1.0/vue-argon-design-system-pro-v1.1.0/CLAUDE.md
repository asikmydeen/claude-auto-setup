# Vue Argon Design System PRO

Vue 2 design system with Bootstrap-Vue. Landing/marketing page focused.

**Framework**: Vue 2.7.14 + Bootstrap-Vue 2.23.1

**Commands**:
- `npm run serve` - Dev server
- `npm run build` - Build
- `npm run lint` - Lint

**Key Directories**:
- `src/components/` - UI components
- `src/views/` - Example pages

**Conventions**:
- Bootstrap-Vue (b-* prefix)
- Element UI (el-* prefix)
- Glide for sliders
