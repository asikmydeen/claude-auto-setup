# Vue Black Dashboard PRO

Vue 2 admin dashboard with dark theme and Bootstrap 4.

**Framework**: Vue 2.7.14 + Element UI 2.15.12 + Bootstrap 4.6.0

**Commands**:
- `npm run serve` - Dev server
- `npm run build` - Build
- `npm run lint` - Lint

**Key Directories**:
- `src/components/` - Components
- `src/views/` - Pages
- `src/i18n/` - Translations

**Conventions**:
- Dark theme design
- Element UI (el-* prefix)
- PWA enabled
- i18n support
