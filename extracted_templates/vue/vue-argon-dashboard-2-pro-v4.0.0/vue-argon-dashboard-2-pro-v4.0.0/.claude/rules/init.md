# Vue Argon Dashboard 2 PRO - Quick Start

## Prerequisites
- Node.js (version specified in package.json engines)
- npm or yarn

## Setup Steps
1. Install: `npm install`
2. Dev server: `npm run serve`
3. Build: `npm run build`

## Environment
Configure environment variables in `.env` if needed.

## First Run
- Vue CLI dev server
- Hot reload enabled
