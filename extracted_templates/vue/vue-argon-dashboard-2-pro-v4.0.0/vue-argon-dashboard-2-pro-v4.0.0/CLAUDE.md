# Vue Argon Dashboard 2 PRO

Vue 3 admin dashboard with Bootstrap 5 and Argon design.

**Framework**: Vue 3.4.19 + Vue CLI 5.0.8 + Bootstrap 5.3.3

**Commands**:
- `npm run serve` - Dev server
- `npm run build` - Build
- `npm run lint` - Lint

**Key Directories**:
- `src/components/` - Components
- `src/views/` - Pages
- `src/store/` - Vuex

**Conventions**:
- Vue 3 Composition API
- Bootstrap 5 classes
- Argon design tokens
