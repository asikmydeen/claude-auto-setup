# Vue Paper Dashboard 2 PRO

Vue 2 admin dashboard with Paper design system.

**Framework**: Vue 2.6.14 + Vue CLI 4.5.14 + Element UI 2.15.6

**Commands**:
- `npm run dev` - Dev server
- `npm run build` - Build

**Key Directories**:
- `src/components/` - Components
- `src/views/` - Pages

**Conventions**:
- Paper design
- Element UI components
- PWA enabled
- vue-notifyjs notifications
