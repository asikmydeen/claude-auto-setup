# Vue Now UI Kit PRO

Vue 2 UI kit with Now UI design. Landing page focused.

**Framework**: Vue 2.6.14 + Vue CLI 5.0.8 + Bootstrap 4.6.0

**Commands**:
- `npm run serve` - Dev server
- `npm run build` - Build
- `npm run deploy` - Deploy to gh-pages

**Key Directories**:
- `src/components/` - Components
- `src/views/` - Pages
- `docs/` - Documentation

**Conventions**:
- Now UI design
- Parallax effects
- PWA support
