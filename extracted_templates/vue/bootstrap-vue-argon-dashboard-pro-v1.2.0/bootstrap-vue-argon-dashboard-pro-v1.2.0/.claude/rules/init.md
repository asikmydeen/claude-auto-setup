# BootstrapVue Argon Dashboard PRO - Quick Start

## Prerequisites
- Node.js 12+ and npm 5+
- Modern browser (Chrome, Firefox, Safari, Edge)

## Setup Steps
1. Install dependencies: `npm install`
2. Start dev server: `npm run serve` (opens browser automatically)
3. Build for production: `npm run build`

## Environment
No `.env` file required for basic setup. Configure API endpoints in `src/config.js` if needed.

## First Run
- Dev server runs on `http://localhost:8080` (default)
- Hot reload enabled for development
- Production build outputs to `dist/`
