# BootstrapVue Argon Dashboard PRO

Premium Vue 2 admin dashboard with Bootstrap-Vue and extensive chart/map integrations.

**Framework**: Vue 2.7.14 + Bootstrap-Vue 2.23.1 + Element UI

**Commands**:
- `npm run serve` - Start dev server
- `npm run build` - Production build
- `npm run lint` - Lint code

**Key Directories**:
- `src/components/` - Reusable UI components
- `src/views/` - Page components
- `src/assets/` - Static assets and styles

**Conventions**:
- Bootstrap-Vue components (`b-*` prefix)
- SCSS modules for component styles
- Vue Router for navigation
- Element UI for forms (`el-*` prefix)
