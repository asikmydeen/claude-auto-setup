# Vue White Dashboard PRO

Vue 2 dashboard with clean white design.

**Framework**: Vue 2.7.14 + Vue CLI 3.12.1 + Element UI 2.15.12

**Commands**:
- `npm run serve` - Dev server
- `npm run build` - Build
- `npm run lint` - Lint

**Key Directories**:
- `src/components/` - Components
- `src/views/` - Pages

**Conventions**:
- White design theme
- Element UI
- Social sharing
- i18n support
