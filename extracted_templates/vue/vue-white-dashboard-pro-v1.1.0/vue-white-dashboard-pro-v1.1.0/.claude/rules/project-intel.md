# Vue White Dashboard PRO

## Project Overview
Premium Vue 2 admin dashboard with clean white design and Bootstrap.

## Tech Stack
- **Framework**: Vue 2.7.14
- **Build Tool**: Vue CLI 3.12.1
- **UI Library**: Element UI 2.15.12
- **CSS**: SASS 1.56.1
- **Router**: Vue Router 3.0.3
- **Validation**: vee-validate 2.2.15
- **i18n**: vue-i18n 8.14.1

## Key Dependencies
- FullCalendar 4.4.2
- Chart.js 2.9.4, vue-chartjs 3.5.1
- D3.js 7.7.0, Datamaps 0.5.9
- SweetAlert2 7.33.1 (older version)
- vue-social-sharing 2.4.6
- vue-github-buttons 3.1.0
- vue2-google-maps 0.10.7
- vue-clickaway 2.2.2
- vue-throttle 0.2.3

## Scripts

- `npm run lint` - Lint code

## Key Patterns
- Clean white design aesthetic
- Vue CLI 3 (older version)
- Element UI components
- vee-validate 2.x (older API)
- Social sharing integration
- vue-throttle for performance
- i18n support

## Known Gotchas
- Vue CLI 3 (not 4 or 5)
- vee-validate 2.x (different API than v3/v4)
- SweetAlert2 7.x (older version)
- core-js 2.6.5 (Vue 2 legacy)
