# Vue Now UI Dashboard PRO

Vue 3 admin dashboard with Now UI design and Bootstrap 4.

**Framework**: Vue 3.0.11 + Vue CLI 4.5.15 + Bootstrap 4.6.1

**Commands**:
- `npm run serve` - Dev server
- `npm run build` - Build
- `npm run lint` - Lint

**Key Directories**:
- `src/components/` - Components
- `src/views/` - Pages

**Conventions**:
- Now UI design
- Element Plus components
- vee-validate forms
