# Vue Now UI Dashboard PRO

## Project Overview
Premium Vue 3 admin dashboard with Now UI design system and Bootstrap 4.

## Tech Stack
- **Framework**: Vue 3.0.11
- **Build Tool**: Vue CLI 4.5.15
- **UI Library**: Element Plus 1.0.1-beta.24
- **CSS**: Bootstrap 4.6.1, SASS 1.43.4
- **Router**: Vue Router 4.0.1
- **Validation**: vee-validate 4.7.3 + yup 0.32.11

## Key Dependencies
- FullCalendar 5.11.3
- Chart.js 2.9.4, vue-chartjs 3.5.1
- D3.js 7.7.0, Datamaps 0.5.9
- SweetAlert2 11.6.15
- vue-toastification 2.0.0-beta.9
- @tweenjs/tween.js 18.6.4
- nouislider 15.6.1

## Scripts
- `npm run serve` / `npm run dev` - Dev server with auto-open
- `npm run build` - Production build
- `npm run lint` - Lint code

## Key Patterns
- Now UI design language
- Vue 3 with Options API
- Element Plus components
- Bootstrap 4 layout
- vee-validate 4 with yup
- Toast notifications
- Chart.js visualizations

## Known Gotchas
- Vue 3 with Bootstrap 4 (not 5)
- Element Plus (Vue 3 version)
- vue-chartjs might need Chart.js compatibility
