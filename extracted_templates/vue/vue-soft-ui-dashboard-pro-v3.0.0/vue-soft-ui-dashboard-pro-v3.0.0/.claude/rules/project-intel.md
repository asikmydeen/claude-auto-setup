# Vue Soft UI Dashboard PRO

## Project Overview
Premium Vue 3 admin dashboard with Soft UI design system and Bootstrap 5.

## Tech Stack
- **Framework**: Vue 3.2.0
- **Build Tool**: Vue CLI 4.5.15
- **UI Framework**: Bootstrap 5.1.3 (Soft UI theme)
- **State Management**: Vuex 4.0.2
- **Router**: Vue Router 4.0.14
- **Icons**: FontAwesome 6.0.0
- **CSS**: SASS 1.43.3

## Key Dependencies
- FontAwesome (core, solid, regular, brands, vue-fontawesome)
- FullCalendar 5.10.1
- Chart.js 3.6.0
- Choices.js 9.0.1
- Dragula 3.7.3
- Dropzone 6.0.0-beta.1
- jKanban 1.3.1
- Leaflet 1.7.1 (maps)
- PhotoSwipe 4.1.3
- Quill 1.3.6
- Three.js 0.124.0 (3D graphics)
- vue-count-to 1.0.13
- vue-star-rating 2.1.0
- vue-sweetalert2 5.0.2
- vue-tilt.js 1.1.1
