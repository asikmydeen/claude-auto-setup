# Vue Soft UI Dashboard PRO

Vue 3 dashboard with Soft UI design and Bootstrap 5.

**Framework**: Vue 3.2.0 + Vue CLI 4.5.15 + Bootstrap 5.1.3

**Commands**:
- `npm run serve` - Dev server
- `npm run build` - Build
- `npm run lint` - Lint

**Key Directories**:
- `src/components/` - Components
- `src/views/` - Pages
- `src/store/` - Vuex

**Conventions**:
- Soft UI design
- Vue 3 Composition API
- Three.js 3D support
