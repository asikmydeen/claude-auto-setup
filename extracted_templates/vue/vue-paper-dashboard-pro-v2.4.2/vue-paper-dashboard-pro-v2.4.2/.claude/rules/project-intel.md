# Vue Paper Dashboard PRO

## Project Overview
Updated Vue 2 admin dashboard with Paper design system (v2.4.2).

## Tech Stack
- **Framework**: Vue 2.7.16
- **Build Tool**: Vue CLI 4.5.14
- **UI Library**: Element UI 2.15.14
- **CSS**: SASS 1.43.2
- **Router**: Vue Router 3.5.2
- **Validation**: vee-validate 3.4.13

## Key Dependencies
- FullCalendar 6.1.15 (newer version)
- Chart.js 2.9.3, vue-chartjs 3.5.1
- D3.js 7.9.0, Datamaps 0.5.9
- SweetAlert2 11.12.4
- Perfect Scrollbar 1.5.5
- vue-notifyjs 0.4.3
- nprogress 0.2.0
- vue-clickaway 2.2.2
