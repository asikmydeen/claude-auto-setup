# Vue Paper Dashboard PRO

Vue 2 dashboard with Paper design (updated version).

**Framework**: Vue 2.7.16 + Vue CLI 4.5.14 + Element UI 2.15.14

**Commands**:
- `npm run dev` - Dev server
- `npm run build` - Build

**Key Directories**:
- `src/components/` - Components
- `src/views/` - Pages

**Conventions**:
- Paper design
- Element UI
- PWA enabled
