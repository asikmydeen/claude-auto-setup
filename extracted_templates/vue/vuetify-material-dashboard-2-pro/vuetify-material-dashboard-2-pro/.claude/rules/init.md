# Vuetify Material Dashboard 2 PRO - Quick Start

## Prerequisites
- Node.js 12+
- npm 5+

## Setup Steps
1. `npm install`
2. `npm run serve` (opens browser)
3. `npm run build` for production

## Environment
Vuetify configuration in `src/plugins/vuetify.js`.

## First Run
- Full Vuetify component library
- Material Design 2 interface
