# Vuetify Material Dashboard 2 PRO

Vue 2 dashboard with Vuetify Material Design components.

**Framework**: Vue 2.6.14 + Vuetify 2.5.10

**Commands**:
- `npm run serve` - Dev server
- `npm run build` - Build
- `npm run lint` - Lint

**Key Directories**:
- `src/components/` - Components
- `src/views/` - Pages
- `src/plugins/` - Vuetify config

**Conventions**:
- Vuetify components (v-* prefix)
- Material Design 2
- Vuelidate validation
