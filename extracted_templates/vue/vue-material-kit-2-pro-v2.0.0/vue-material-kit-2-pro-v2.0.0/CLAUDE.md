# Vue Material Kit 2 PRO

Vue 3 UI kit with Vite and Material Design. Landing page focused.

**Framework**: Vue 3.2.36 + Vite 2.9.9 + Bootstrap 5.1.3

**Commands**:
- `npm run dev` - Vite dev
- `npm run build` - Build
- `npm run lint` - Lint

**Key Directories**:
- `src/components/` - Components
- `src/views/` - Pages
- `src/stores/` - Pinia stores

**Conventions**:
- Pinia for state
- Material Design
- Marketing focus
