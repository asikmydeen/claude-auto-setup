# Vue Material Kit 2 PRO - Quick Start

## Prerequisites
- Node.js 14+
- npm 7+

## Setup Steps
1. `npm install`
2. `npm run dev`
3. `npm run build` for production
4. `npm run preview` to test build

## Environment
Vite uses `.env` files for environment variables.

## First Run
- Fast Vite HMR
- Material Design UI kit
