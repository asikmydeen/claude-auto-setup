# Argon Dashboard PRO Node.js

Full-stack Node.js dashboard with EJS templates, Express, PostgreSQL, Redis sessions, and Passport auth.

**Tech Stack**: Node.js • Express 4 • PostgreSQL • Knex • Redis • Passport • EJS • Gulp • PM2

**Commands**:
- `npm run dev` - Start with PM2 + Gulp watch
- `npm start` - Production server
- `npm run knex` - Database migrations/seeds

**Key Directories**:
- `routes/` - Express route handlers
- `views/` - EJS templates
- `db/` - Knex migrations and seeds
- `src/` - Source SCSS and JS
- `public/` - Compiled assets

**Prerequisites**: PostgreSQL, Redis server
