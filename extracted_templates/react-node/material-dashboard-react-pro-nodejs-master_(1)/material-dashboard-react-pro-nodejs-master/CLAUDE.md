# Material Dashboard React PRO + Node.js

Full-stack Material Design dashboard with React 18, MUI 5, and Node.js API supporting PostgreSQL, MySQL, or MongoDB.

**Tech Stack**: React 18 • MUI 5 • Express • Sequelize/Mongoose • JWT • Passport • Formik • Chart.js • FullCalendar • CASL

**Commands**:
```bash
# Frontend
cd material-dashboard-react-pro && npm install --legacy-peer-deps && npm start

# Backend
cd node-api-pro && npm install && npm run start:dev
```

**Key Directories**:
- `material-dashboard-react-pro/src/layouts/` - Page layouts
- `node-api-pro/src/routes/` - API endpoints
- `node-api-pro/src/models/` - Database models
- `node-api-pro/src/config/` - Database config

**Prerequisites**: Node.js 14-18, Database (PG/MySQL/MongoDB)
