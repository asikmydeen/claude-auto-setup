# Argon Dashboard PRO React + Node.js

Full-stack dashboard with React frontend and Node.js/MongoDB backend. JWT authentication, charts, tables, forms.

**Tech Stack**: React 17 • Express • MongoDB • Mongoose • JWT • Passport • Chart.js • Reactstrap • CRA

**Commands**:
```bash
# Backend
cd backend && npm start

# Frontend
cd frontend && npm start
```

**Key Directories**:
- `frontend/src/views/` - React pages
- `frontend/src/components/` - Reusable components
- `backend/routes/` - API endpoints
- `backend/models/` - Mongoose schemas

**Prerequisites**: MongoDB database
